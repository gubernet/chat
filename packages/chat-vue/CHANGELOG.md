# Changelog

All notable changes to `@layeral/chat-vue` are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html), the same as `@layeral/chat`'s.

## [Unreleased]

## [0.7.0] - 2026-11-27

### Changed

- **The package is now `@layeral/chat-vue`**, on `@layeral/chat-element` 0.7.0;
  `@gubernet/chat-vue` is deprecated. The component is `LayeralChat` (was `GubernetChat`).

## [0.6.0] - 2026-11-23

### Changed

- On `@gubernet/chat-element` 0.6.0: a tool that needs the user's account at one of the
  organization's identity providers asks for it with the provider's sign-in button.

## [0.5.0] - 2026-11-22

### Added

- `GubernetChat` for Vue 3, on `@gubernet/chat-element`: the props of the chat,
  `v-model:conversation-id` and the `bar-end` slot.
