# Gubernet chat

Open-source React components for chatting with AI agents built on [Gubernet](https://gubernet.ai).

| Package                           | What it is                   |
| --------------------------------- | ---------------------------- |
| [`@gubernet/chat`](packages/chat) | The chat as React components |

## Development

Node.js 22 or later and pnpm.

```bash
pnpm install
pnpm build
pnpm test
```

Before a commit: `pnpm format`, `pnpm lint`, `pnpm type-check` and `pnpm test`.
